# 💻 SQLAgent Pro Frontend

Modern Web Studio for **SQLAgent Pro**, built with React 18, Vite 6, Tailwind CSS v4, and Lucide Icons.

---

## 🚀 Features

- **Interactive Schema Explorer**: Inspect all tables, columns, primary keys, and sample data.
- **Natural Language Query Prompt**: Type business questions in plain English with 1-click preset suggestions.
- **Interactive Results Data Table**: Live search, row count, execution time in ms, and CSV export.
- **Dynamic Visual Charts**: Automatic SVG/HTML5 bar charts based on LLM visualization recommendations.
- **Generated SQL Inspector**: Syntax highlighting and 1-click clipboard copy.
- **Executive Business Takeaways**: Automatic natural language summary of data findings.

---

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

App runs at `http://localhost:5174` and proxies API requests to `http://127.0.0.1:8001`.
